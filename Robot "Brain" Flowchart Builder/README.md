# Robot "Brain" Flowchart Builder (Sense → Think → Act)

An interactive browser-based flowchart builder for designing a simple robot control loop using the **Sense → Think → Act** architecture. Users can drag and drop blocks onto the canvas, edit block labels directly, and add a loop-back arrow to represent the continuous control cycle.

## Concepts demonstrated

* HTML5 Drag & Drop API using `dragstart`, `dragover`, `drop`, and `dataTransfer`
* `contentEditable` for inline block-label editing
* Sense–Think–Act architecture used in robotics control systems
* Interactive flowchart construction and visual representation
* Loop-back visualization for continuous robot behavior
