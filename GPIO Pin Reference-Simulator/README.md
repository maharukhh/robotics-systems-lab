# GPIO Pin Reference/Simulator (Raspberry Pi 40-Pin)

An interactive browser-based reference and simulator for the **Raspberry Pi 40-pin GPIO header**. The interface displays power, ground, and GPIO pins using a visual pin layout, while GPIO pins can be clicked to simulate HIGH/LOW logic states.

## Concepts demonstrated

* Data-driven GPIO pin layout rendered from a `PINS` array
* Visual distinction between power, ground, and general-purpose I/O pins
* Interactive HIGH/LOW state simulation for GPIO pins
* Per-pin state management using a JavaScript `state` object
* Raspberry Pi GPIO header structure and digital logic concepts
