# Robotics Systems Lab

A growing collection of robotics and intelligent-systems projects covering **path planning, control systems, kinematics, sensor simulation, state estimation, swarm behavior, and interactive robotics tools**.

Built while studying Robotics and Intelligent Systems, this repository combines algorithmic implementations in Python with interactive simulations built using HTML, CSS, and JavaScript.

## Overview

This repository explores practical robotics concepts through standalone algorithms, mathematical models, simulations, and browser-based visualizations.

The projects cover both **robot intelligence and motion** — including planning routes, controlling movement, estimating position from noisy sensors, modeling robot kinematics, simulating sensors and actuators, and visualizing multi-agent behavior.

## Purpose

This repository serves as a practical robotics portfolio focused on learning by implementation.

Each project takes a robotics concept and turns it into a working algorithm, simulation, or interactive tool. Together, the projects demonstrate experience across motion planning, control, kinematics, sensing, state estimation, embedded concepts, and intelligent multi-agent behavior.

The long-term goal is to continue expanding the laboratory with more advanced robotics algorithms, simulations, and autonomous-system concepts.
