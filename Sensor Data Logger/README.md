# Sensor Data Logger (Mock Data, Downloadable CSV)

A browser-based sensor data logging interface that simulates temperature and distance sensor readings. Each reading is timestamped and displayed in a scrollable table, with the option to export all captured data as a CSV file.

## Concepts demonstrated

* Simulated temperature and distance sensor data
* Timestamped sensor data collection
* Interval-based logging into an in-memory array
* Dynamic rendering of an append-only data table
* Generating CSV data using JavaScript
* Client-side file downloads using `Blob` and `URL.createObjectURL`
