# Maze Solver Visualizer (BFS / DFS)

An interactive browser-based maze solver that visualizes **Breadth-First Search (BFS)** and **Depth-First Search (DFS)** on a customizable grid. Users can draw walls, select a search algorithm, and watch the exploration process from a green start cell to a red target cell, with the final path highlighted.

## Concepts demonstrated

* Grid-based **BFS** using a queue and **DFS** using a stack
* Comparing BFS and DFS pathfinding behavior
* Path reconstruction using a `cameFrom` map
* Animated algorithm visualization using `async/await` and `setTimeout`
* Interactive wall placement and grid-based navigation
* Visual representation of explored cells and the final path
